# 🐾 Sistema Veterinario Móvil

Aplicación móvil para gestión veterinaria desarrollada con React Native, Expo y TypeScript.

## 🚀 Tecnologías
- React Native
- Expo
- TypeScript
- Axios (para API calls)
- React Navigation
- AsyncStorage

## 📱 Características
- ✅ Login de usuarios
- ✅ Conexión a API Express
- ✅ Navegación entre pantallas
- ✅ Manejo de sesiones
- ✅ UI/UX moderna

## 🔧 Instalación
```bash
git clone https://github.com/Sexernal/sistema_veterinario_mobile.git
cd sistema_veterinario_mobile
npm install
npx expo start
